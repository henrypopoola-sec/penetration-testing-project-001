Phase 1: Scope Definition

1. Project Purpose

The purpose of this project is to develop practical knowledge of ethical penetration testing through structured security assessment exercises.

2. Target Identification

- Primary learning domain: example.com
- Domain purpose: Reserved example domain.
- Assessment type: Educational passive reconnaissance and HTTP analysis.

3. Authorization and Boundaries

example.com is used for passive learning and basic public information analysis only.

Active scanning, exploitation and vulnerability testing will be performed exclusively in intentionally vulnerable labs or environments where explicit authorization has been granted.

4. Permitted Activities

- Public DNS information collection.
- WHOIS information analysis.
- Basic HTTP header inspection.
- Documentation of publicly available information.

5. Prohibited Activities

- Unauthorized port scanning.
- Exploitation attempts.
- Denial-of-service testing.
- Accessing restricted systems or data.
- Any activity that disrupts services.

6. Testing Methodology

The project follows a structured approach:

1. Scope definition.
2. Passive reconnaissance.
3. DNS enumeration.
4. HTTP analysis.
5. Technology identification.
6. Authorized lab-based network discovery.
7. Vulnerability assessment.
8. Final reporting.

7. Limitations

This is a beginner educational project. Findings will be limited to activities actually performed and verified.

8. Project Status

Scope definition documented. Practical assessment activities will follow progressively.
